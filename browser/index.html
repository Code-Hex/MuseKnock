Worker setup

Prepare the six secrets for your Worker. Values stay in this tab until you copy them. Keep your tokens in your password manager before closing or reloading the page.

Access tokens

For a new installation, generate one token each for the webhook sender, read-only connector, and admin connector. If you already have these tokens, keep using them.

Muse device

Choose your authorized device’s pairing.json or Muse Desktop Bridge state.json. This page reads the file in your browser. Stop the executor for that identity before handing it over to the Worker.

Save and connect

  1. In the Cloudflare dashboard, open this Worker and choose Settings → Variables and Secrets. Add each value as a Secret and deploy the changes.
  2. In Muse, add a custom connector using the URL below and MCP_ADMIN_TOKEN as its Bearer token.
  3. Ask Muse to register your existing side chat by name and exact session ID. The first registration becomes the destination on a fresh Worker. Ask it to list the registered chats to check the active one.
